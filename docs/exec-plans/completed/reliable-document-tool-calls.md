# Reliable document tool calls

## Goal

Keep the `create_document` catalog entry concise while making its arguments
unambiguous and ensuring all persisted provenance is generated by AcornOps.

## Completed changes

- Added model-facing descriptions to `title`, `markdown`, and `format` without
  changing the user-visible tool description.
- Removed advertised provenance and the schema-level format default; the
  executor retains its existing PDF default.
- Removed caller provenance merging. Legacy direct input remains tolerated but
  is ignored, and persisted provenance contains authoritative run identifiers.
- Added catalog and database-backed provenance/idempotency regression coverage.

## Validation

- Passed typecheck, style, contract, harness, build, migration-chain static,
  authorization, membership, and run-event durability checks.
- Nine focused schema, PDF/Markdown format, Workflow/target/Agent-chat
  idempotency, and authoritative-provenance tests passed against a migrated
  disposable Postgres database.
- Repository validation was invoked, but database-backed tests require the
  unavailable `CONTROL_PLANE_TEST_DATABASE_URL` and local Postgres service.
- The independent OpenAPI check reached a pre-existing stale admin OpenAPI
  artifact; this change does not modify public or admin API schemas.
